# Evidence And Test Records

This directory stores milestone evidence, test records, and interview-ready summaries.

## Purpose
The goal is to keep a durable record of:
- what we tested
- how we tested it
- what happened
- what architectural lesson we learned

## Structure
- `templates/`: reusable markdown templates
- `phase-1/` through `phase-6/`: phase-specific evidence and reports

## Usage
For each meaningful run:
1. create a test record in the relevant phase folder
2. record the exact commands and key observations
3. summarize the architectural lesson

For each milestone:
1. create a milestone report
2. summarize validated behavior, gaps, and next steps

This directory is meant to be publishable and interview-friendly, not just a dump of terminal output.
